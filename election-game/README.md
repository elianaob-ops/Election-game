# בול בקלפי

משחק ניחושי מנדטים בעברית, עם נקודות בלבד. נדרש Node.js 24 ומעלה, ללא התקנת חבילות.

```sh
npm start
```

פתחו http://localhost:3000 וצרו תחרות עם רשימת המפלגות ומועד נעילה. שתפו רק את קישור ההשתתפות ושמרו את קישור הניהול הפרטי. לאחר הנעילה, הזינו את התוצאות דרך קישור הניהול.

הניקוד הוא 120 פחות מחצית סכום ההפרשים המוחלטים. הניחושים נשמרים ב־SQLite; זיהוי המשתתף לעדכון נשמר בדפדפן. אין אימות זהות או מניעת השתתפות כפולה ממכשירים שונים. קישור הניהול מעניק שליטה בתוצאות, ואין מנגנון שחזור אם הוא אובד.

להפעלה ציבורית יש לארח תהליך Node עם HTTPS ודיסק קבוע, ולגבות את מסד הנתונים. אפשר להגדיר PORT ו־DB_PATH. ברירת המחדל היא פורט 3000 וקובץ game.sqlite. הקובץ אינו מתאים לפריסה בכמה שרתים במקביל. לפני פתיחה לקהל רחב יש להוסיף הגבלת קצב בקשות; הגרסה הנוכחית מתאימה לקבוצת חברים עם קישור.

## פרסום דרך GitHub ו־Render

1. צרו מאגר GitHub חדש והעלו את תוכן תיקיית הפרויקט לשורש המאגר, כולל render.yaml ו־Dockerfile. אין להעלות קובצי sqlite או קישור ניהול של תחרות.
2. היכנסו ל־Render באמצעות GitHub ובחרו New → Blueprint.
3. חברו את המאגר ובדקו את פירוט המחיר לפני אישור הפריסה. ההגדרה משתמשת בשירות Starter ובדיסק קבוע, בתשלום. אין כאן ביצוע רכישה אוטומטי.
4. לאחר שהפריסה במצב Live, פתחו את כתובת השירות, צרו תחרות ושתפו את קישור ההשתתפות בלבד.

הדיסק הקבוע מונע אובדן ניחושים בעת עדכון או הפעלה מחדש. גיבויים עדיין באחריות מפעיל השירות. אין להריץ יותר ממופע אחד של האפליקציה עם SQLite זה.

הפרויקט טרם פורסם. קובצי הפריסה מוכנים ל־Render, אך הפריסה בענן לא נבדקה בפועל.
