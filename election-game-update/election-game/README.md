# בול בקלפי

משחק ניחושי מנדטים בעברית, עם נקודות בלבד. נדרש Node.js 24 ומעלה. הפעלת השרת אינה דורשת חבילות חיצוניות.

```sh
npm start
```

פתחו http://localhost:3000. העמוד הראשי מתחיל בהרשמה בשם וממשיך למסך בחירת מנדטים דרך כרטיסי המפלגות. לחיצה על כרטיס מאפשרת לבחור 1–120 מנדטים. הסרת בחירה משאירה את המפלגה עם 0. הניחוש נשמר רק כשסך המנדטים הוא 120 ולוחצים על כפתור השמירה.

העמוד הראשי משתמש בקלפי משותפת להדגמה, שנוצרת בעת הפעלת מסד חדש וננעלת לאחר שבעה ימים. זו אינה תחרות עם קישור ניהול לבעלים. לניהול תחרות מלאה ופרסום תוצאות, היכנסו ל־/manage: בחרו מפלגות, ערכו את השמות ומועד הנעילה וצרו תחרות. שתפו רק את קישור ההשתתפות ושמרו את קישור הניהול הפרטי. לאחר הנעילה, הזינו את התוצאות דרך קישור הניהול.

קטלוג המפלגות והאיורים נמצא ב־public/parties.json. השיוך של האיורים לתחרות נשמר בנפרד משמות המפלגות, כך שניתן לערוך את הכותרות בעת יצירת תחרות. הגלריה ב־/characters מציגה שמות מפלגות. כרטיס רע״ם מאחד את עבאס וסגלוביץ׳; הציבור החרדי מציג את מוטי לייטנר וד״ר נחומי יפה.

הניקוד הוא 120 פחות מחצית סכום ההפרשים המוחלטים. הניחושים נשמרים ב־SQLite; זיהוי המשתתף לעדכון נשמר בדפדפן. אין אימות זהות או מניעת השתתפות כפולה ממכשירים שונים. קישור הניהול מעניק שליטה בתוצאות, ואין מנגנון שחזור אם הוא אובד.

ההרשמה היא בשם בלבד, עם מזהה אקראי בדפדפן. זו אינה מערכת חשבונות עם סיסמה או אימות דוא״ל. ניחוש קודם ניתן לשחזור רק באמצעות המזהה הפרטי. השינויים במסד מוסיפים טבלאות ואינם משנים תחרויות קיימות.

## בדיקות

```sh
npm test
npm ci
npm run test:ui
```

בדיקות השרת מכסות הרשמה, שמירה, נעילה, ניקוד ושחזור. בדיקת הממשק משתמשת ב־jsdom להפעלת מסלול הרשמה, פתיחת כרטיסים, בחירת 1–120, תיקון חריגה ועדכון ניחוש. היא אינה מחליפה בדיקה חזותית בדפדפן.

## מקורות לאיורים ולכותרות

כותרות הרשימות המשותפות נקבעו לפי בחירת יוצרת המשחק. נחומי יפה ומוטי לייטנר זוהו לפי [אתר הציבור החרדי](https://hatzibur-haharedi.org/). יתר השמות נבדקו מול פרסומי הרשימות, לרבות [עמך ישראל](https://amchaisrael.co.il/), [המכון הישראלי לדמוקרטיה — המילואימניקים](https://www.idi.org.il/policy/parties-and-elections/parties/miluimniks/) ו[חד״ש־תע״ל בערוץ הכנסת](https://www.knesset.tv/מפלגות/47334/). האיורים הם קריקטורות סאטיריות, ואינם תצלומים.

להפעלה ציבורית יש לארח תהליך Node עם HTTPS ודיסק קבוע, ולגבות את מסד הנתונים. אפשר להגדיר PORT ו־DB_PATH. ברירת המחדל היא פורט 3000 וקובץ game.sqlite. הקובץ אינו מתאים לפריסה בכמה שרתים במקביל. לפני פתיחה לקהל רחב יש להוסיף הגבלת קצב בקשות; הגרסה הנוכחית מתאימה לקבוצת חברים עם קישור.

## פרסום דרך GitHub ו־Render

1. צרו מאגר GitHub חדש והעלו את תוכן תיקיית הפרויקט לשורש המאגר, כולל render.yaml ו־Dockerfile. אין להעלות קובצי sqlite או קישור ניהול של תחרות.
2. היכנסו ל־Render באמצעות GitHub ובחרו New → Blueprint.
3. חברו את המאגר ובדקו את פירוט המחיר לפני אישור הפריסה. ההגדרה משתמשת בשירות Starter ובדיסק קבוע, בתשלום. אין כאן ביצוע רכישה אוטומטי.
4. לאחר שהפריסה במצב Live, פתחו את כתובת השירות, צרו תחרות ושתפו את קישור ההשתתפות בלבד.

הדיסק הקבוע מונע אובדן ניחושים בעת עדכון או הפעלה מחדש. גיבויים עדיין באחריות מפעיל השירות. אין להריץ יותר ממופע אחד של האפליקציה עם SQLite זה.

הפרויקט טרם פורסם. קובצי הפריסה מוכנים ל־Render, אך הפריסה בענן לא נבדקה בפועל.
