# דבי פוליטי בוחרת

משחק ניחושי מנדטים בעברית, עם נקודות בלבד. נדרש Node.js 24 ומעלה. השרת משתמש ב־SQLite המובנה ב־Node, ללא חבילות בזמן הריצה.

שם האתר הוא **דבי פוליטי בוחרת** ושם הקלפי הראשית **הקלפי של דבי פוליטי**. הנעילה: **27.10.2026 בשעה 06:59, שעון ישראל**. זהו 04:59 UTC, לאחר המעבר לשעון חורף. הגדרות המיתוג והמועד נמצאות ב־public/config.json. התאריכים במסך המשחק מוצגים לפי Asia/Jerusalem, גם למשתתף שנמצא באזור זמן אחר.

## עדכון השירות הקיים ב־Render

1. חלצו את debbie-community-update.zip. העלו את **התוכן** שלו, לרבות Dockerfile, server.mjs, auth.mjs ותיקיית public, אל התיקייה הקיימת:
   `Election-game/election-game-update/election-game`.
   אין להעלות תיקיית עטיפה חדשה או ZIP סגור.
2. בצעו Commit changes. ה־Root Directory נשאר `election-game-update/election-game`.
3. בשירות הקיים ב־Render היכנסו ל־Environment והוסיפו:

| Key | Value |
| --- | --- |
| COMMUNITY_ADMIN_USER | debbie או שם משתמש אישי אחר באנגלית, 3–40 תווים |
| COMMUNITY_ADMIN_PASSWORD | סיסמת ניהול פרטית שתבחרו, לפחות 12 ועד 128 תווים |

הזינו את הסיסמה **רק ב־Render**. אל תעלו אותה ל־GitHub, אל תשתפו אותה בקבוצה ואל תשלחו אותה בצ׳אט. בחרו סיסמה ייחודית. לחצו Save, rebuild, and deploy. חשבון הניהול נוצר מתוך ההגדרות האלה; לא נרשמים אליו בטופס הציבורי. בהיעדר הגדרה תקינה האתר מציג מסך הכנה וכל נתוני המשחק נשארים חסומים.

4. אחרי Live, היכנסו לכתובת האתר עם שם המשתמש וסיסמת הניהול. הקישור **אישור משתתפים** פותח את /members. הזנת תוצאות זמינה למנהלת אחרי הנעילה.
5. נסו במכשיר נוסף או בחלון פרטי: הרשמה, המתנה לאישור, אישור במסך הניהול, כניסה, חלוקה של 120 ושמירת ניחוש. בדקו את האייקון ותיקוני הדמויות במחשב ובנייד. לא בוצעה בדיקה חזותית בדפדפן בסביבת הפיתוח.

**שמירת נתונים:** במסלול Free של Render מערכת הקבצים זמנית. חשבונות, אישורים, תמונות וניחושים עלולים להימחק בהפעלה מחדש או בפריסה. לפני שימוש אמיתי בקהילה יש להגדיר דיסק קבוע המותקן ב־/data ו־DB_PATH=/data/game.sqlite, ולגבות אותו. זה מצריך שירות שתומך בדיסק קבוע; אין בחבילה פעולה שמחייבת את החשבון אוטומטית. render.yaml כולל תצורת Starter עם דיסק 1GB למי שבוחר במפורש לפרוס Blueprint בתשלום. הוספת משתני הסביבה לשירות קיים נעשית במסך Environment, לא באמצעות שינוי ה־Blueprint בלבד.

## הכניסה לקהילה

המשתתפים נרשמים עם שם שמוכר בקבוצת הוואטסאפ, שם משתמש אישי וסיסמה של 10–128 תווים. אחרי ההרשמה הם שולחים לדבי **מתוך קבוצת הוואטסאפ** את שם המשתמש שבחרו. דבי משווה את הפרטים ומאשרת או דוחה ב־/members. שם שמישהו מקליד אינו הוכחת חברות; יש לאמת את הבקשה דרך הקבוצה לפני אישור. אין חיבור אוטומטי למידע על חברי וואטסאפ, ואין שליחת הודעות מטעם האתר.

חשבון ממתין או דחוי אינו יכול לקרוא את המשחק, הדירוג, תמונות המשתתפים או ניחושים, ואינו יכול לשמור ניחוש. ההגנה נאכפת בשרת, לרבות גישה דרך API ישיר. ביטול אישור מבטל את כל החיבורים של אותו משתתף. הממשק בודק אישור מחדש כל 15 שניות. רק המנהלת יכולה לאשר חברים, לפתוח תחרויות או להזין תוצאות. קישור ניהול ישן אינו מחליף כניסה לחשבון המנהלת.

סיסמאות נשמרות כ־scrypt עם מלח אקראי; חיבור מזוהה באמצעות עוגיית HttpOnly, SameSite=Strict ו־Secure בייצור, למשך עד 14 יום. רק גיבוב מזהה החיבור נשמר במסד. סיסמאות אינן נשמרות בדפדפן בידי האפליקציה. יש הגבלת ניסיונות כניסה והרשמה והגבלת עבודות גיבוב במקביל. את מזהה הפרופיל הפרטי אין לפרסם. מזהי תמונות נפרדים ממנו, והתמונות מוגשות רק לחשבונות מאושרים עם private, no-store.

גישה מאושרת אינה מונעת צילום מסך, העתקת איורים ציבוריים או מסירת סיסמה לאחר. אין אימות דוא״ל, אימות דו־שלבי או שחזור סיסמה אוטומטי. סיסמת המנהלת ניתנת לשינוי במשתנה הסביבה; שינוי שלה מבטל את החיבורים הקודמים של המנהלת. כדי להחליף שם משתמש למנהלת יש לבחור שם שאינו שייך למשתתף קיים; חשבונות ניהול קודמים מבוטלים.

השדרוג מוסיף טבלאות ומשמר נתונים קיימים. בפרופיל הישן השמור באותו דפדפן ניתן לקשר ניחוש ישן לחשבון חדש במהלך ההרשמה, ורק לאחר אישור המנהלת הוא נגיש שוב. הזדהות בשם זהה לבדו אינה משחזרת ניחוש של מישהו אחר. בהיעדר הזיהוי הישן לא מתבצע שיוך אוטומטי. ניחושים ישנים ללא חשבון מאושר נשמרים במסד ואינם מוצגים בדירוג. בפריסה למסד חדש כתובת הקלפי הראשית נשמרת, אך הדבר אינו משחזר נתונים שנמחקו.

## המשחק והאיורים

אחרי האישור נכנסים לפרופיל, בוחרים תמונה או משאירים דמות ברירת מחדל, וממשיכים למסך המפלגות. לחיצה על דמות פותחת בחירה של 1–120 מנדטים. הסרת הבחירה משאירה את המפלגה עם 0. בחירה של 4 משאירה 116 לחלוקה. שמירה מתאפשרת רק בסכום 120, ולאחריה מוצג סיכום בסדר יורד. אפשר לעדכן עד הנעילה. טבלת הדירוג כוללת את כל המשתתפים המאושרים שנרשמו לתחרות, כולל מי שעדיין לא שמר ניחוש.

האייקון מבוסס על הקריקטורה הזוגית מהתמונה שסופקה. בנט בג׳ינס; עיני סמוטריץ׳ תוקנו גם בכרטיס המשותף וגם באיור הבודד. כרטיס ביחד מציג את לפיד ובנט, רע״ם מציג את עבאס וסגלוביץ׳, הציונות הדתית את סמוטריץ׳ ופייגלין, המילואימניקים והכלכלית את הנדל וזליכה, וחד״ש־תע״ל את טיבי ועודה. הציבור החרדי מציג את מוטי לייטנר וד״ר נחומי יפה. האיורים סאטיריים ונוצרו באמצעות בינה מלאכותית.

קטלוג המפלגות נמצא ב־public/parties.json. במסך /manage, למנהלת בלבד, אפשר לפתוח תחרות נוספת, לשנות את השמות ולהסיר מפלגות. שיוך האיור נשמר בנפרד מכותרת המפלגה. מועד הנעילה בטופס מפורש תמיד לפי שעון ישראל, גם אם הדפדפן באזור זמן אחר. התחרות הראשית והקישור הקהילתי הקיים עודכנו פעם אחת למועד ולשם החדשים, תוך שימור הבחירות.

הניקוד הוא 120 פחות מחצית סכום ההפרשים המוחלטים לעומת התוצאות. תמונת משתתף מוקטנת בדפדפן ל־256×256; השרת מקבל JPG/PNG/WebP עד 128KiB. הקובץ אינו מתאים להפעלת כמה שרתים במקביל מול אותו SQLite.

## פיתוח ובדיקות

לפיתוח מקומי הגדירו COMMUNITY_ADMIN_USER ו־COMMUNITY_ADMIN_PASSWORD בסביבת התהליך ואז הריצו:

```sh
npm start
```

פתחו http://localhost:3000. DB_PATH קובע את נתיב המסד; PORT קובע פורט. ברירת המחדל היא game.sqlite ופורט 3000. אין סיסמת ניהול ברירת מחדל. הפעלת Docker נועדה לשרת HTTPS מאחורי Render; NODE_ENV=production מפעיל עוגיות Secure.

```sh
npm test
npm ci
npm run test:ui
```

בדיקות השרת מכסות הגדרה סגורה כברירת מחדל, הרשמה ממתינה, אישור, דחייה וביטול חיבור, חסימת קריאה אנונימית, בידוד ניחושים ופרופילים, שמירת תמונות, הפעלה מחדש, שדרוג מסד ושחזור פרופיל קודם. הן בודקות גם את נעילת 27.10 לפי שעון החורף בישראל, אימות קלט וניקוד. בדיקת jsdom מכסה הרשמה ואישור דרך הממשק, בחירת מנדטים, יתרה, סיכום ממויין, עריכה, תמונות וברירת מחדל וביטול גישה. פענוח תמונה ו־canvas מדומים ב־jsdom; יש לבדוק צילום אמיתי והצגה בנייד לאחר הפריסה.

שמות הרשימות המשותפות נבחרו על ידי יוצרת המשחק. מקורות הרקע לאיורים כוללים את [אתר הציבור החרדי](https://hatzibur-haharedi.org/), [עמך ישראל](https://amchaisrael.co.il/), [המכון הישראלי לדמוקרטיה — המילואימניקים](https://www.idi.org.il/policy/parties-and-elections/parties/miluimniks/) ו[חד״ש־תע״ל בערוץ הכנסת](https://www.knesset.tv/מפלגות/47334/).
